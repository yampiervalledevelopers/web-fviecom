# FV.IECOM S.A.S. — Soluciones Integrales de Ingeniería ⚡📡🏗️

Sitio web oficial de **FV.IECOM S.A.S.**, empresa dedicada al diseño, construcción, consultoría y mantenimiento de infraestructura tecnológica, eléctrica y civil con sede en Medellín, Colombia.

---

## 🚀 Áreas de Especialización

- ⚡ **Ingeniería Eléctrica y Energía:** Diseño y ejecución de redes eléctricas de media y baja tensión, subestaciones, tableros y sistemas de respaldo.
- 📡 **Telecomunicaciones y Redes:** Cableado estructurado, redes de fibra óptica, data centers y conectividad corporativa.
- 🤖 **Seguridad Electrónica y Automatización:** Sistemas de videovigilancia (CCTV), control de acceso biométrico, alarmas y automatización industrial/domótica.
- 🏗️ **Obras Civiles:** Adecuaciones locativas especializadas, obras complementarias y montaje de infraestructura.

## 🛠️ Tecnologías Empleadas
- **Frontend:** HTML5 semántico, Tailwind CSS (diseño responsivo y moderno), JavaScript.
- **Backend / Entorno:** Python (servidor local y utilidades de automatización).
- **Control de Versiones:** Git & GitHub.
- **Integraciones:** Formspree (formulario de cotizaciones), WhatsApp Business API, Google Maps embebido.

---

## 💻 Ejecución Local

Para visualizar el sitio en tu computadora localmente, puedes usar Python:

```bash
# Iniciar servidor local en el puerto 8000
python -m http.server 8000
```

Luego abre tu navegador en:
`http://localhost:8000`
